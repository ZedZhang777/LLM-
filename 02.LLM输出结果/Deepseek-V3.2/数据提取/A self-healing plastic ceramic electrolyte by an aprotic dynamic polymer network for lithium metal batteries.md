# A self-healing plastic ceramic electrolyte by an aprotic dynamic polymer network for lithium metal batteries - Data Extraction

## Electrolyte Composition

| Component | Material | Content/Conditions |
|-----------|----------|--------------------|
| Polymer Matrix | Copolymer network of EA and MTFSI (for SH-SPE); PA-SPE (for buffer layer) | |
| Monomer | Ethyl acrylate (EA), (Trifluoromethane) sulfonimide lithium methacrylate (MTFSI) | For SH-SPE: EA and MTFSI. For PA-SPE: EA and Ethylene glycol dimethylacrylate (EDA). |
| Lithium Salt | LiTFSI, MTFSI (monomer salt), LATP ceramic | LiTFSI in SH-SPE and PA-SPE; LATP (70 wt% in PCE) |
| Lithium Salt Concentration | Not explicitly stated in molarity | 70 wt% LATP in PCE |
| Solvent | Solvent-free; Succinonitrile (SN) as solid crystal plasticizer | |
| Additives | Fluoroethylene carbonate (FEC) | 5 wt% in SH-SPE and PA-SPE |
| Initiator | Phenylbis(2,4,6-trimethylbenzoyl) phosphineoxide (PPO) for SH-SPE; Azobisisobutyronitrile (AIBN) for PA-SPE | PPO (photoinitiator) for SH-SPE; AIBN (thermal initiator) for PA-SPE |
| Crosslinking Agent | None for SH-SPE (non-covalent dynamic bonds); Ethylene glycol dimethylacrylate (EDA) for PA-SPE | |
| Polymerization Method | UV polymerization for SH-SPE; Thermal polymerization for PA-SPE | |
| Polymerization Conditions | SH-SPE: UV irradiation (365 nm) for 10 min; PA-SPE: 65°C overnight | |
