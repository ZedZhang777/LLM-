# Bioinspired gel polymer electrolyte for wide temperature lithium metal battery - Data Extraction

## Electrolyte Composition

| Component | Material | Content/Conditions |
|-----------|----------|--------------------|
| Polymer Matrix | PTFMA (Poly(trifluoroethyl methacrylate)) | Formed via in-situ polymerization |
| Monomer | TFMA (Trifluoroethyl methacrylate) | 20 wt% |
| Lithium Salt | LiTFSI (Lithium bis(trifluoromethanesulphonyl)imide) | 1 M |
| Lithium Salt Concentration | 1 M | In FEP solvent |
| Solvent | FEP (Ethyl 3,3,3-trifluoropropanoate) | Main solvent |
| Additives | FEC (Fluoroethylene carbonate) | 5 wt% |
| Initiator | AIBN (2,2'-Azobis(2-methylpropionitrile)) | 0.5 wt% |
| Crosslinking Agent | PEGDA (Poly(ethylene glycol) diacrylate, Mn = 575) | 1 wt% |
| Polymerization Method | In-situ radical polymerization | Thermal polymerization |
| Polymerization Conditions | 70°C for 5h | Single-step curing |
