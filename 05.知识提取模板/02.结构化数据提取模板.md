## 数值提取注意事项

1. **科学计数法**：统一使用 `× 10ⁿ` 或 `e` 格式
2. **单位一致性**：
   - 电导率：S cm⁻¹
   - 浓度：M (mol/L) 或 mol%
   - 载量：mg cm⁻²
   - 容量：mAh g⁻¹ 或 mAh cm⁻²
3. **温度表示**：统一使用 °C 或 K
4. **化学式**：使用正确下标（如 LiTFSI、LiPF₆、NCM811）
